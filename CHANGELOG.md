# Changelog

## 1.0.0 - unreleased

- First release: a Converter Studio menu in Writer, Calc, Impress and Draw.
- Insert HEIC, HEIF and AVIF pictures and camera RAW photos (CR2, NEF, ARW, DNG).
- Text from a scanned PDF or a photo (OCR), in 19 languages, as a new document or as plain text at
  the cursor.
- Open EPUB, MOBI and AZW3 e-books as documents.
- Settings: the API key in LibreOffice's saved passwords, a credit limit per file, the API address.
- English and Turkish.
